Entry for [The Most Boring Object, Reviewed in One Line](https://make.fun/competitions/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3) on make.fun.

A Node 22 TypeScript program (`main.ts`, stdlib only) that writes exactly one
line — a funny, true review of the most boring everyday object, the dustpan —
to `entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes `/tmp/out/entry.txt` containing the single-line review.
